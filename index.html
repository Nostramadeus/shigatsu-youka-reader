Read Shigatsu Youka as a web page

死月妖花～四月八日～ by New++ (free LiveMaker visual novel). This page shows the whole game as still pictures and text, nothing moves, nothing makes a sound, and the game's one screamer is not included. It unlocks scenes in the same order as the game, so it does not spoil the structure.

What a page looks like

Natsumi
One row is one text box of the game, next to the picture that was on screen for it. You scroll down at your own pace.

How it works

  • Scenes unlock like the game. At the start only the first scene is listed. Mark a scene as read (button at its end, or scroll to the end) and the scenes it unlocks appear. The story chart shows the same thing as the game's navigator: time flows down, lines connect a scene to the scenes it follows.
  • Progress stays in your browser. Nothing is sent anywhere. Use Export progress at the bottom of the scene list to save a small file, and Import progress on another device. Clearing site data erases the marks.
  • No spoilers by default. Locked scenes, table rows and arcs are hidden until reached. "Reveal everything" shows all of it at once; it asks first.
  • What is missing on purpose. Sound, music, screen shakes, fades, timed effects, the one screamer (the English patch ships a note about it). Animated pictures show one frame. Videos show their first frame. Choices inside a scene are not shown. Scenes with a branch or a hidden route start with a "Play options" panel like the game's navigator (from the start, from just before the branch, the other branch, the hidden route); an option opens by the game's rule, approximated from the scenes you marked read.
  • Mika's live commentary, chatter topics, the encyclopedia and the reference documents are under "Tables" on the scene list, gated the same way.

Playing the real game

The game is free: freem game 19917. The English patch and its notes (including how the screamer triggers and how to switch it off in the game) are at the translation repository. This reader is built from the same translation.

Unofficial fan project. Pictures and text belong to the game's author. If you are the author and want this taken down, open an issue on the repository and it will be removed.

Built from the game's own scripts and tables. No tracking, no cookies beyond your browser's local storage.
