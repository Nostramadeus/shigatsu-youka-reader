　　Unselected topic

　　Unlocking topic
　By selecting this topic, you can unlock another related topic

　　Unlocked topic
　A topic unlocked by selecting another topic

　　Choice-unlocking topic
　By selecting a particular choice, you can unlock another topic. However, if you reselect a different choice while that topic has appeared, the unlocked topic returns to its locked state.

　　Choice-unlocked topic
　A topic unlocked by selecting a particular choice in a particular topic. However, if you reselect a different choice in the unlocking topic, this topic returns to its locked state.

　　Topic in season
　A topic that can no longer be selected once the scenarios have advanced to a certain point. Miss its season and it can never be selected again. Please select it early.

　　One-time topic
　A topic that can be selected only once. Once selected, it can never be selected again.

　　Affection-changing topic
　A topic in which particular choices change affection

　　Info button
　Displays a list of information on the chatter so far.

※3
