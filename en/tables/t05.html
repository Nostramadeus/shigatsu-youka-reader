070What Is a Reference?Allow me to explain the references. A reference is, as I said at the outset, material for coming to know this world.It is not that you must necessarily check them, but if you wish to know this world more deeply, active viewing is recommended.Some of them are difficult and call for advanced knowledge, so if one concerns you, looking it up on the internet would be advisable.Conversely, some references are of no use whatsoever, so the power to judge whether one is needed is also called for.Yet it is not rare for something that looks of no use to be important information later on.In any case, if you wish to know this world deeply, checking every one without omission would be best.An unviewed reference carries a 'New!!' mark.New

341About the FormatsReferences are classified, as a rule, into two kinds: object and scenario.The object format comes in various kinds, such as documents, web pages and tangible things, but the operation is the same for all.オブジェクトIn the scenario format a short story unfolds, almost the same as a scenario of the main work.シナリオThere seem to be unknown formats among them as well, but, if I may presume, I do not have a grasp of those either.
452About the Formatsリファレンスは基本的にオブジェクト、シナリオ、書簡、レポートの2つに分類されます。オブジェクト形式では、書類、ホームページ、有形物等、様々な種類がございますが、操作方法等はどれも同じです。オブジェクトシナリオ形式では、本編のシナリオとほぼ同等の短いストーリーが展開されます。シナリオ書簡形式では昔に書かれた手紙を閲覧することができます。しかし全てを読むためにはポイントを消費しなくてはなりません。レポート形式では、戦前に書かれた報告書を閲覧することができます。こちらもまた、ポイントを消費することで読める範囲が広がります。

962The Letters Format書簡形式は横長の手紙で、初めのうちはほどんどが隠れていて読むことができません。手紙部分をクリックし続けるとポイントを消費しつつ、読める範囲が広がっていきます。ただし、ポイントが枯渇するとそれ以上読める範囲を広げることができませんのでご注意ください。また書簡は基本的に汚れが多く、はっきりと読むことができません。すべての範囲を読めるようにすると、汚れが消えて鮮明な文字が浮かび上がってきます。詳細は、書簡リファレンス選択時のヘルプをご参照ください。
1052The Report Formatレポート形式はある組織の報告書なのですが、大部分が欠けていてまともに読むことができません。ポイントを消費すると、欠けているパーツを追加することが可能です。クイックメニュー画像しかし、そのパーツはパズルのように散乱しているので、マウス操作で正しい位置に戻してやる必要があります。すべてのパーツを正しい位置に当てはめると、書面の汚れが消えて鮮明な文字が浮かび上がってきます。パーツの詳しい操作方法は、レポート画面内のヘルプをご参照ください。

1252About Pointsこのようなポイントがあるのにお気づきでしょうか。ポイントこのポイントは、シナリオ本編やリファレンスの閲覧、雑談で加算されていきます。ポイント書簡形式、レポート形式で読める範囲を広げるために、このポイントを消費しなくてはなりません。ポイント書簡形式では、紙を引いていくほどにポイントがどんどん減少していきます。レポート形式では、パーツを追加するたびにポイントを消費します。
1340Reference LockVery rarely there is a reference that cannot even be viewed unless a set condition is met.Even if it is unlocked, you cannot enter the viewing screen unless the condition is met.The condition for unlocking the lock is not announced, so I am afraid you must search it out yourself.The one thing I can say is that the lock is released by viewing other references.
